# Pong Game

![Pong Game Screenshot](https://danielgaudreault.github.io/Pong/screenshot.png)

A classic Pong game implementation with both 1v1 and 1vAI modes, built with Python and Pygame.

[Play Now](https://danielgaudreault.github.io/Pong/)

## Features

- 🎮 Two game modes: Player vs Player or Player vs AI
- ⚡ Dynamic ball physics with speed increases on paddle hits
- 📊 Score tracking (first to 5 points wins)
- 🖥️ Clean menu interface
- 🎨 Classic retro styling

## How to Play

### Controls

**Player 1 (Left Paddle):**
- `W` - Move up
- `S` - Move down

**Player 2 (Right Paddle - 1v1 mode only):**
- `↑` (Up Arrow) - Move up
- `↓` (Down Arrow) - Move down

**General Controls:**
- `ESC` - Return to menu
- `1` - Select 1v1 mode
- `2` - Select 1vAI mode
